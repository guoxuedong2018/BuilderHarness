## 安装量对比

基线来自提交 `616350c2712bcc7bc7465890469234e4e90c3b08` 的实际 0.8.0 tarball；0.9.0 也是源码实际打包。相同 Node.js v24.19.0、相同机器、相同标准 npm 安装命令，安装生命周期脚本关闭，TLS 与 npm 完整性校验保持默认。

| 安装对象 | node_modules 中实际文件字节数 | 本次安装耗时 |
|---|---:|---:|
| 0.8.0 默认能力 | 233,519,750 | 14,211 ms |
| 0.9.0 基础能力 | 2,829,097 | 1,651 ms |
| 0.9.0 基础 + 可选浏览器配置包 | 204,577,056 | 浏览器增量阶段 4,918 ms |

数值是该次快照的文件字节量，不含 npm 缓存、文件系统元数据与稀疏分配开销。时间受网络与缓存影响，不是性能保证；后续文档修改会小幅改变主包字节数。依赖分离减少基础安装成本，未声称浏览器本身变轻。

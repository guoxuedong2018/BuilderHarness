# 画面与动效准则

每条是一句可执行的规则 + 为什么。前缀标来源：〔VS〕video-shotcraft 的判例（其用户返工得来）、〔MG〕mg-styles-15 的制作规范、
〔本仓库〕本仓库的约束与实测。可以有意违反，但要在 `index.html` 顶部注释写明违反了哪条、为什么。

## 节奏

1. **关键信息落定后停住 ≥1.2 秒再动。**〔VS R1〕他们全片六次节奏反馈全是「放慢、停一下」，没有一次「太慢」。第一版默认再慢一档。
2. **没有匀速运动。**〔VS R2〕相机用 `ease.inOut`，元素入场用 `ease.standard`；匀速读作廉价幻灯片。
3. **同一时刻只有一个东西在动。**〔MG〕相机在推，标注就别同时出；标注出完，再动下一个。
4. **交互演示按真人操作的速度走。**〔VS R3〕光标 0.8 秒滑到目标，读者要能跟着做一遍。
5. **首尾同一帧，周期性动效整除总时长。**〔本仓库〕群聊里动图无限循环，接缝处一跳就像卡了。

## 画面

6. **本仓库的界面一律用活的原型，外部页面才截图。**〔VS Q1、本仓库〕手搓仿真界面被他们的用户整下午作废过一次；
   本仓库第一版机评宣传图（手画播放器与夜景）被否，第二版（截成静态图再推拉）被指出「没用上源码与上下文」。
   手画只用于标注、光标、字卡这些界面上本来没有的东西。
7a. **画面里说话的只有字卡、窗口标题栏、标注，不套固定版式。**〔本仓库〕字卡整屏一句价值，放在开头和转折处；标题栏写入口路径；
   标注贴在元素旁、只补画面上没有的话。用户 2026-10-28 否掉了「左栏文案 + 右侧窗口」的模板（每张图长一个样）；
   2026-11-05 给了参考片，字卡与窗口进了画面——它们按时间出现又退场，不是一直占着一栏。
7b. **画面要和线上一致。**〔本仓库〕物料是给用户看的线上功能，原型里还没上线的不能出现。标注里每句话也要在线上核对过：
   2026-11-02 第一版「从已有 Case 挑」照原型拍，多了线上没有的左侧筛选面板、少了「已选 N 条 Case」，返工一次。
7. **视觉语言取产品自己的。**〔VS 核心理念 2〕主色、危险色、正文色、字体、圆角取 `web/src/styles/theme.less`；不另造一套「宣传皮肤」。
   红色只给「问题」用，和产品里的语义一致。
8. **读字的时候正视。**〔VS Q6、本仓库〕窗口的俯仰只给建立「在哪儿」的镜头（升起、全景、退场）；推近、抽离、标注出现时一律 `tilt: [0, 0]`。
   不带俯仰时舞台用 2D 变换，文字按新倍率重新栅格化；带俯仰时整块走合成层，推近会发虚。
9. **字发虚先查是不是用了截图。**〔VS Q2〕活的原型是矢量，推多近都清楚；只有外部页面的截图会糊：清晰度 = 截图倍率 ÷（相机放大 × 渲染倍率），
   要推得近就把那一屏拍成 3x（`promo.config.mjs` 的 `scale`）。
10. **一个镜头最多一处强调效果。**〔VS Q4〕脉冲、聚光、描边光只给主角一次；群发即廉价。
11. **标注、光标落在元素的真实位置上。**〔VS Q9〕位置一律取 `app.box(sel)`，不手量像素；选择器优先用源码里稳定的类名与组件名。
    能让真组件反馈的不手画：提示气泡、抽屉、悬停态都交给产品自己。渲染时光标就是真鼠标（CDP），日志报「被 … 挡住」时先看画面：
    多半是有东西盖在要点的地方。
11a. **要讲「怎么用」的那一块，抽离出来讲。**〔本仓库，2026-11-05 参考片〕推近只是放大，旁边的东西还在抢视线；`isolate` 把页面其余部分淡掉、
    组件垫卡片浮起来，它自己照常运行。一个场景一两次；抽离的东西要关掉（弹窗、抽屉）之前先结束抽离。

## 字

12. **要读的字有下限，按最终像素量。**〔VS Q11〕在 960 宽的 GIF 上：标注主句 ≥ 18px、小字 ≥ 15px（舞台默认 26 / 21px，画布 1280 宽）；
    推近后的产品文字 ≥ 12px（原型 12–14px 的字推到 1.3 倍以上）。自检：把海报缩到 480 宽（群聊里没点开时的大小），主角还看得出是什么吗？
13. **字只有两种状态：纹理，或要读。**〔VS Q11〕截图里的小字是纹理，读者不用读；想让读者读的，就用标注重写一遍、给够字号。
    没有「放大了一点但还是看不清」的中间态。
14. **文案在画面定稿后按最终画面重写一遍。**〔VS C1〕初稿只是占位；每句和它出现时的画面对得上吗？
15. **标题带功能名与具体收益，不用抽象隐喻。**〔VS C2〕见 angles.md。

## 群聊里的 GIF

16. **背景用纯色或极浅的色差，不铺大面积渐变、光晕、噪点。**〔本仓库〕GIF 只有 256 色：大渐变出色带，噪点让体积翻倍。
17. **整屏运动是体积的大头。**〔本仓库〕GIF 逐帧只存变化的部分；推、摇、整屏淡入每一帧都整屏重画。
    10 秒里整屏运动累计别超过 4 秒；超了 5MB 先缩短整屏运动，再考虑降帧率。
18. **默认无声。**〔本仓库〕要配乐只出在 MP4 里，且声音不能承载信息——静音看也得懂。

## 数据与确定性

19. **画面里只有合成数据。**〔宿主的数据边界〕拍摄带 `promo` 标记；不拍正式环境快照、本机素材；画面里不出现内部链接、真实账号。
20. **每一帧都确定。**〔MG〕原型那一侧由虚拟时钟管（定时器、动画帧、CSS 过渡、日期都按帧拨）；合成页这一侧（镜头、标注、光标）写成 t 的纯函数，
    不用 `Date.now()`、`Math.random()`、CSS transition。动作只在时间轴上发生，不安排要等网络的动作。同一个 t 渲两次必须一模一样。

## 流程

21. **先静帧，后整片。**〔MG〕6–8 个关键时刻的静帧每一张都要像能单独发的图；静帧不过不出整片。
22. **交付前自己看过、再给独立评委看。**〔VS P1、MG rubric〕首检不交给用户。
23. **参考图逐镜头取舍，不当成全片风格令。**〔VS P2〕用户给了参考，先列「这个手法｜要不要｜为什么」，再动手。
24. **指代含糊的反馈先确认对象。**〔VS P3〕「第一个标注」是哪一个？先问清楚再改。

## 产品价值片补充

25. **首帧不是 Logo，是产品结果。** 观众在信息流里先看到第一帧；Logo 开场只适合已有强认知的品牌。
26. **3 秒内出现产品。** 纯字卡、纯渐变球、纯品牌动画不要超过 3 秒；再美也不能替代产品证据。
27. **一个价值，三个证据，一个 CTA。** 功能列表不是价值；每个证据必须是一个真实界面状态或可核对的数字。
28. **精致感来自对齐、留白、字阶和停顿，不来自特效。** 先检查 8px 网格、左边界、字号层级，再考虑加动效。
29. **每个动效都要有因果。** 镜头推近是因为要看细节；字卡出现是因为要转折；球出现是因为代表 Agent。没有因果的动效删掉。
30. **给声音留位置。** 画面先成立；旁白只补充画面没有的信息。后续接 TTS 时，不改 beat 和时长。

## 交付前自检

- [ ] 首帧单独看：字卡那句话、或主角画面读得清吗？缩到 480 宽呢？首帧里没有光标吗？海报 PNG（`poster` 时刻）单独看呢？
- [ ] 读字的镜头都是正视的吗？抽离的那一块是读者此刻该看的吗？
- [ ] 渲染日志里有没有「被 … 挡住，改用合成点击」？
- [ ] 标注有没有压住它要讲的那个东西（按钮、状态标签、翻页）？字卡说过的话，标注有没有再说一遍？
- [ ] 海报里有光标吗？画面里有「原型」字样吗？
- [ ] 画面里的界面是活的原型吗？真组件能自己反馈的（提示、抽屉、悬停）有没有被手画代替？
- [ ] 每个场景到线上核对过吗？画面里有没有还没上线的东西？
- [ ] 配文写了吗？入口路径和导航上的字一模一样吗？
- [ ] 每句文案有出处吗？没上线的有没有写成已上线？
- [ ] 停顿：每个标注落定后停 ≥1.2 秒了吗？有没有两个东西同时在动？
- [ ] 循环：最后一帧和第一帧是同一个画面吗？脉冲周期整除总时长吗？
- [ ] 标注有没有复述画面里已经看得见的字（包括产品自己的提示气泡）？
- [ ] 清晰度：推得最近的那一刻，MP4 裁剪放大看字边缘，有没有发虚？
- [ ] 体积：GIF ≤ 5MB？
- [ ] 数据：画面里只有合成数据？没有内部链接、真实账号？

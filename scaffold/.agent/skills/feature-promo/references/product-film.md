# 产品价值片：无真人的产品宣传方法

这支片子不靠真人、口播和舞台。主角是**产品本身**，用真实界面、克制的动效、准确的文字和精致的细节，让读者在 3 秒内知道“这是什么、对我有什么用、为什么值得信”。

适用：官网首屏、发布会预热、Product Hunt、销售提案、社媒信息流、应用商店预览。
默认时长：15 秒 / 30 秒；45 秒只用于需要解释机制的复杂产品。

## 1. 先定一句话价值

在写分镜前，只能留下一句话：

```text
[谁] 可以 [完成什么结果]，不用 [原来的代价]。
```

例：

- 产品团队可以在发布前看见需求、页面和源码的偏差，不用靠聊天记录回忆。
- 财务团队可以在一个界面里核对整份投资备忘录，不用逐页翻 PDF。
- 开发者可以让 Agent 按真实页面反馈修改，不用反复描述“右上角那个按钮”。

这句话决定 Hook、Proof 和结尾 CTA。写不出来，不要开始做动效。

## 2. 三种时长结构

### 15 秒：一句价值 + 一个证据

| 时间 | 节拍 | 画面 |
|---|---|---|
| 0–2.5s | Hook：反常识结果 / 前后对比 / 产品高光 | 首帧就是结果，不要 Logo 开场 |
| 2.5–6s | Value：一句话价值 | 产品界面 + 大字号价值句 |
| 6–11s | Proof：一个真实交互 | 点击、状态变化、结果出现 |
| 11–15s | Close：品牌 + CTA | 产品名、一句话、网址/按钮 |

### 30 秒：Hook → Value → Proof → Detail → Close

| 时间 | 节拍 | 任务 | 画面建议 |
|---|---|---|---|
| 0–3s | Hook | 让人停下来 | 结果画面、异常对比、产品高光特写 |
| 3–8s | Value | 说清对谁有什么用 | 产品全景 + 一句价值字幕 |
| 8–18s | Proof | 证明不是概念 | 2–3 个真实操作，每个 3–5 秒 |
| 18–24s | Detail | 展示精致与可信 | 微交互、数据、引用、权限、导出 |
| 24–30s | Close | 记住品牌 | 产品名 + 一句话 + CTA，停 ≥2 秒 |

### 45 秒：多一个“怎么运作”

在 Proof 后加 10–12 秒机制段：

```text
输入 → 处理 → 可检查的结果 → 人的确认
```

机制段只讲一条主线，不要变成功能列表。

## 3. 七种 Hook，优先用前三种

1. **结果先行**：首帧就是完成后的界面，再倒回去讲怎么做到。
2. **前后对比**：旧流程 5 步 vs 新流程 1 步，同一视口、同一构图。
3. **异常高光**：一个红点、一处错误、一条被标出的风险，先制造注意力。
4. **数字冲击**：有出处的数字，例如“70 页 → 1 个界面”；没有出处就不要用。
5. **问题句**：只写一句用户会点头的话，不写“你是否也在苦恼”。
6. **产品动作**：光标点下按钮，结果在 1 秒内出现。
7. **品牌符号**：渐变球、网格、产品色块，只适合已有认知的品牌。

不要用：黑底白字“Introducing…”开场、Logo 动画 3 秒、无意义的粒子/光效。

## 4. 视觉系统：先像产品，再像广告

### 画布与网格

- 主片 16:9，1920×1080；需要 4K 时同比例放大。
- 安全边距 96px；重要文字不进入边缘 64px。
- 8px 网格；标题、正文、按钮共享同一左边界。
- 一屏只用一个视觉中心；不要把 UI、标题、卖点、Logo 同时塞满。

### 字体与字阶

| 层级 | 参考字号（1080p） | 用途 |
|---|---|---|
| Display | 72–96px | Hook、结果数字 |
| H1 | 48–64px | 价值句 |
| H2 | 32–40px | 段落标题 |
| Body | 24–28px | 解释 |
| Caption | 18–20px | 来源、注释 |

- 中文用产品已有字体；没有就用思源黑体/苹方，不要混用三种以上字体。
- 标题最多两行；一行只表达一个意思。
- 数字用 `tabular-nums`，小数点对齐。

### 色彩

- 主色只从产品 token 取；强调色只给“变化/结果/风险”。
- 背景用 off-white / charcoal，不用大面积渐变。
- 渐变只给品牌符号（如 Agent 球），不要给整屏背景。
- 同一镜头最多一个强调色；红色只给问题，不给装饰。

### 产品界面

- 用真实运行中的页面，不用手绘仿真。
- 录屏/截图至少 2x，避免推近发虚。
- 去掉浏览器地址栏、开发工具栏、真实账号和内部链接。
- 统一视口；同一支片不要一会儿 1280 宽、一会儿 1440 宽。
- 合成数据要像真实数据：有长有短、有异常、有边界。

## 5. 镜头不是唯一手段：五种构图

只在一个页面上推拉，会像“产品录屏加了运镜”，不像一支片。每 4–6 秒换一次**构图结构**，即使还是同一个产品：

| 构图 | 用途 | 做法 |
|---|---|---|
| **暗场标题** | Hook / 章节 | 深色背景 + 大字；产品只露出一块细节，不铺满 |
| **产品窗口** | 价值 / 全景 | 把产品放进圆角窗口卡片，带轻微阴影；文字在窗口外 |
| **细节特写** | Proof / 精致感 | 只裁一个区域（一个按钮、一条引用、一个状态），配一条标注 |
| **浅色证据页** | 数据 / 可信度 | off-white 背景 + 1–2 个 UI 卡片 + 数字/标签；大量留白 |
| **品牌结尾** | Close | 纯色背景 + 品牌名 + 一句话 + CTA，不再出现完整界面 |

切换方式：

- 硬切最稳；不要每个转场都加缩放/模糊。
- 白场/黑场只用于“换状态”，0.3–0.5 秒。
- 同一支片里，产品窗口的位置和尺寸可以变，但圆角、阴影、边框保持一致。
- 不要让标题卡压住产品主标题；要么把产品裁到窗口里，要么给文字独立区域。

**一个 30 秒片的构图节奏可以是：**

```text
0–3.5   暗场标题 + 一小块产品细节
3.5–9   浅色产品窗口 + 左侧价值句
9–15    暗场细节特写 + 一条标注
15–21   浅色证据页 + 数字/状态
21–26   产品窗口收束 + 品牌句
26–30   品牌结尾
```

## 6. 动效语法：少、慢、有因果

### 允许的动效

- 镜头推近/拉远/平移：0.8–1.0s，`ease.inOut`。
- 文字遮罩上移/淡入：0.4–0.6s，`ease.out`。
- UI 卡片依次出现：0.3s/张，间隔 0.08–0.12s。
- 数字滚动：0.8s，只滚有出处的数字。
- 渐变球缓慢漂浮：8–12s 一个周期，幅度 ≤ 12px。
- 白场/黑场过渡：0.4–0.6s，用于换状态，不用于遮丑。
- 擦除对比：0.8s，旧/新同视口。
- 聚光/压暗：只给一个主角，0.4s。

### 禁止的动效

- 弹跳、回弹超过 2%、果冻感。
- 全屏粒子、镜头光晕、故障 glitch、随机抖动。
- 每个元素都在动；同一时刻只能有一个主动作。
- 用 `Math.random()`、`Date.now()`、CSS transition 做画面状态。
- 用缩放掩盖低分辨率截图。

### 节奏

- 关键信息落定后停 ≥1.2 秒。
- 一个镜头只讲一个动作。
- 每 3–5 秒换一次构图，但不要每 0.5 秒切一次。
- 首尾可以同帧，方便循环；产品价值片不强制循环。

## 7. 简单品牌动效配方

以下效果足够撑起一支“高级感”产品片，不需要 3D：

1. **品牌渐变球**：两个径向渐变 + 轻微模糊，缓慢缩放/位移；作为 Agent、智能、连接的视觉符号。
2. **动态字卡**：一行大标题 + 一行小字；用遮罩上移，不要逐字弹跳。
3. **UI 卡片堆叠**：2–3 张产品卡片错位排列，依次进入；最后一张成为主角。
4. **指标数字**：大数字 + 小标签 + 来源；从 0 滚到目标值。
5. **Logo 墙**：灰度网格，0.05s 错峰淡入；不要拉伸、加阴影、加描边。
6. **擦除对比**：旧流程/新流程同视口，竖线从左到右；不要用两张不同尺寸的截图。
7. **聚光灯**：背景压暗 45%，目标圆角镂空；只给一个主角。
8. **结尾卡**：产品名 + 一句价值 + CTA；停 2.5 秒，不要堆二维码、地址、版权。

具体 CSS/JS 写法见 [motion-recipes.md](motion-recipes.md)。

## 8. 声音先留位置，不急着做

当前可以无声交付，但分镜要标记声音点，方便后续接 TTS/音乐：

```js
// VO: 0.5–3.0  “发布前，先看见偏差。”
// SFX: 3.0 click / 8.4 whoosh / 18.0 soft tick
// MUSIC: 90–105 BPM, minimal electronic, -18 LUFS bed
```

规则：

- 旁白不承载画面已经表达的信息；没有旁白也能看懂。
- 音乐只做情绪和节奏，不抢产品点击音。
- 后续接声音合成时，先锁定画面时长，再生成配音，避免口型/节拍对不上。
- 输出保留无音轨母版；配音版单独输出。

## 9. 生产流程

```text
1. 一句话价值
2. 选 15/30/45 秒结构
3. 写 5–7 个 beat（每拍一句话 + 一个画面）
4. 选真实产品路由和 2–3 个关键交互
5. 先做静帧：首帧、价值帧、证据帧、细节帧、结尾帧
6. 做 3 个镜头运动，不要做 30 个
7. 加 1–2 个品牌动效（球/字卡/Logo 墙）
8. 渲染 30fps MP4，检查首帧、循环、体积
9. 独立评审，改一轮
10. 后续再加配音/音乐，不改变画面节奏
```

## 10. 常见失败

- **像功能介绍**：每个功能都讲，最后没有一个记住。
- **像模板**：左栏文字、右栏窗口，每张图都一样。
- **像 AI 生成**：紫色渐变、玻璃拟态、无意义光球，和产品无关。
- **像录屏**：没有镜头设计、没有停顿、鼠标乱飞。
- **像广告**：说了“颠覆/赋能/革命”，但没有产品证据。
- **细节脏**：字号不齐、边距不一致、截图发虚、光标停在奇怪位置。

## 11. 交付前自检

- [ ] 3 秒内能说出“这是什么、对我有什么用”？
- [ ] 首帧单独截出来，像一张能发的海报吗？
- [ ] 每个卖点都有产品画面或数据证据吗？
- [ ] 是否只有一个核心价值，而不是 5 个卖点？
- [ ] 同一时刻是否只有一个主动作？
- [ ] 关键信息是否停够 1.2 秒？
- [ ] 字体、颜色、圆角、间距是否来自产品本身？
- [ ] 是否有至少一个“精致细节”（微交互、数据、引用、过渡）？
- [ ] 去掉音乐和旁白，仍然看得懂吗？
- [ ] 结尾是否只留一个 CTA？

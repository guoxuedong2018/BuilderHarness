# 桥段与镜头

镜头词汇来自 video-shotcraft 的镜头库（124 张卡里与工具宣贯相关的那一小部分），按「活的原型 + 窗口机位」重写；
2026-11-05 按用户给的参考片补了字卡、窗口俯仰与组件抽离（骨架 E）。
宣贯卡片不需要 3D 炸开、粒子、追光这类品牌片手法：3D 只用在窗口的俯仰上，界面本身越接近读者每天看到的样子越好。
**能让真组件自己反馈的，就交给它**：悬停出提示、点开出抽屉、输入后列表收窄——这些是产品自己的样子，手画只会更假。

## 桥段：整张卡的骨架

先选骨架，再往里填镜头。时长按 10 秒写，8–15 秒都行；所有数字是起点，不是死规定。

### E · 字卡 → 窗口 → 抽离（默认）

范例：`docs/promo/09202047_EVAL_SET_LOCAL_IMPORT/scenes.js`（四个场景都是这个骨架，`START` / `leave()` / `cut()` 可照抄）。

| 秒 | 画面 | 写法 |
|---|---|---|
| 0–1.9 | 字卡：上方一行入口路径，标题一句价值（关键词主色），副标题一句怎么用；窗口在画面下方等着 | `title` + `kicker` + `exit: "up"`；`camera: "page"` 带 `shift: [0, 640]`、大俯仰 |
| 1.1–2.4 | 字卡上移出画，窗口**直接**升到要操作的那块（不在全景上停） | 场景第一个 `camera`，`move: 1.3`；要读字就 `tilt: [0, 0]` |
| 2.4–5 | 光标真点 / 真拖 / 真输入，产品自己反馈 | `click` / `drop` / `type` |
| 5–10 | 要读的组件抽离出来，正视推近；标注补一句画面上没有的话 | `isolate`（自带推近）或 `isolate` + `camera: false` 自己框；一处聚光用 `keep: 0.2`；只停一两秒的真反馈（成功提示）配 `hold` 定格 |
| 末尾 2.1 秒 | 从当前镜头直接退到画面下方，同时字卡升起，最后 0.3 秒和第 0 秒一模一样 | 收尾字卡 `exit: "cut"`、`bg: "none"`，比退场晚 0.1 秒出来 |

升起、退场不带要读的信息，又是整屏运动（GIF 体积的大头），各压在 1–1.3 秒。
总片里每个场景用 `film: [0, 收尾字卡出现前]` 截掉收尾那张，免得和下一场的开场字卡连着出；片头片尾是 `only: "film"` 的纯字卡场景。

### A · 主角先行（「看得见了」）

范例：`docs/promo/auto-eval-evidence/`。首帧就是主角特写，再倒回去讲它从哪来，首尾接成一圈。

| 秒 | 画面 | 说明 |
|---|---|---|
| 0–1.8 | 特写主角 + 标注①；指针停在红点上，原型自己的提示气泡开着 | 首帧 = 海报帧，没点开也看得懂；`prepare` 里摆好 |
| 1.6–2.5 | 同一档放大摇到第二处细节 | 标注①淡出，②在落定后才出 |
| 2.5–4.4 | 停住看标注② | ≥1.5 秒 |
| 4.6–5.5 | 拉回全景，光标点 × 关掉抽屉 | 抽屉用它自己的过渡收起 |
| 5.7–7.1 | 光标滑到入口，行悬停亮起，点一下 | 讲「在哪儿」；行悬停、抽屉滑出都是真的 |
| 7.6–9.0 | 推回主角，光标滑到红点、悬停 | 提示气泡按组件自己的延时出现 |
| 9.0–10 | 标注①出现、停住 → 接回第 0 秒 | 首尾同一帧：同一个状态，不是同一张图 |

### B · 走一遍（「少一步」「能做了」）

| 秒 | 画面 |
|---|---|
| 0–1.5 | 结果画面（做完之后的样子）+ 标题，当海报 |
| 1.5–2.3 | 切回起点页面（淡入，不飞） |
| 2.3–6 | 光标按真人速度走完操作：每一步落定停 0.4 秒，关键一步标注 |
| 6–7 | 结果出现，推近 |
| 7–10 | 停住看结果 → 接回第 0 秒 |

步骤超过 3 步就是 B 不合适：要么只演最关键的一步，要么换 C 讲「以前 5 步、现在 1 步」。

### C · 前后对比（「少一步」「改名 / 换位置」）

一条竖线从左往右擦过：线左是旧的，线右是新的。旧画面也要用截图（线上实拍或旧版原型）；拿不到旧画面就别做对比，
改用 B——凭记忆画一个旧界面就是编造。

| 秒 | 画面 |
|---|---|
| 0–2 | 新版全貌 + 标题（海报帧） |
| 2–3 | 擦回旧版，角上「以前」小标签 |
| 3–5 | 旧版里把麻烦的那几步依次标出来（序号①②③） |
| 5–6.5 | 擦到新版，「现在」标签，同一处只剩一步 |
| 6.5–10 | 停住 → 接回第 0 秒 |

### D · 一期合集（每周更新）

每个功能 2.5–3 秒：上方功能名（与卡片条目同名）+ 主角裁切图轻推。最后 1.5 秒是期号字卡（「2026-W38 · 6 项更新」）。
合集只讲「有什么」，每项的「怎么用」交给各自的单张卡或操作说明。功能超过 5 个就拆成两张。

## 骨架写成时间轴

骨架里的每一行，就是 `scenes.js` 里的几条时间轴条目（写法见 `promo/stage.js` 文件头）。以 A 为例：

```js
{ at: 0, camera: ROW, fill: 0.96 },                          // 首帧：主角
{ at: 0, until: 2.0, note: HINT, text: "<b class=bad>第 6 行</b>：…", sub: "…" },
{ at: 2.45, dip: 0.5 }, { at: 2.45, click: "text=换个文件", pointer: false },   // 白场里换状态
{ at: 4.2, drop: ZONE, file: (ctx) => ctx.file, chip: "第一批评测数据.xlsx", then: ".ci-file" },
{ at: 5.0, camera: [".ci-file", TABLE], fill: 0.95 },        // 框住几个元素
{ at: 7.7, camera: ROW, fill: 0.96 }, { at: 8.0, note: HINT, … },              // 回到首帧
```

镜头、光标、标注的位置都在渲染前空跑一遍时量好，不写像素。

## 镜头：一个镜头只做一个动作

`kit.js` 已提供补间、关键帧、相机计算；下面写的是参数与坑。缓动默认 `ease.inOut`（相机）与 `ease.standard`（元素入场），都不弹。

| 镜头 | 做法 | 参数起点 | 坑 |
|---|---|---|---|
| **推近 / 拉远** | `camera: 选择器`，`fill` 定占画面多少；倍率在对数空间补间，推拉速度均匀 | 0.8–1.0 秒 | 活页面是矢量，推多近都清楚；不带俯仰时是 2D 变换，文字按新倍率重新栅格化，不发虚 |
| **摇** | 几处特写用 `centerOn(box, 视窗, 同一个 s)`，只平移不变倍 | 0.8–1.0 秒 | 摇的同时缩放，视线会丢 |
| **真组件反馈** | `actions` 里 `click` / `hover` / `leave` / `type` / `setState`，产品代码自己动：抽屉、提示、筛选、加载 | 动作之后留够组件自己的过渡时间（抽屉 ~0.3 秒、提示 ~0.1 秒） | 不安排要等网络的动作；悬停用 `hover`：渲染时是真鼠标（`:hover` 样式也有），预览时逐层派 mouseenter，Tooltip、表格行都认 |
| **光标** | 舞台画的 SVG 光标，滑到元素中心；渲染时真鼠标跟着它走（CDP），点击时按下缩一下、配涟漪；推近时光标跟着变大 | 滑 0.7 秒、涟漪 0.4 秒 | 落点被别的元素挡住时渲染日志会报，并退回合成点击——这一般说明画面也不对 |
| **标注** | 白底卡片 + 2px 主色连线 + 目标点圆点；淡入 + 12px 位移 | 0.3 秒，落定后停 ≥1.2 秒 | 同一时刻只有一个标注；标注贴着被说的东西，可以压在窗口边上，不能压住被说的东西 |
| **聚光** | 不推近也要强调时：其余区域压暗 45%，目标留圆角镂空 | 0.4 秒 | 与推近二选一，不要又推又压暗 |
| **脉冲** | 目标外一圈描边放大淡出 | 周期整除总时长（10 秒配 1.25 秒） | 只给主角一处；周期不整除，循环接缝处会跳一下 |
| **擦除对比** | 新画面层 `clip-path: inset(0 0 0 X%)`，X 补间，竖线跟随；旧的一侧是 `capture` 拍的外部页面截图 | 0.8 秒 | 两边必须同一视口、同一滚动位置，不然线两边对不齐 |
| **数字滚动** | 从 0 补到目标值，字宽用 `tabular-nums` | 0.8 秒 | 只滚有出处的数；没数据就不用这个镜头 |
| **字卡** | `title`：整屏一句价值，逐字升起（`enter: "rise"`）或打字机（`"type"`）；`<b>` 用产品主色；退场 `up` 整块上移露出窗口 | 入场 0.6 秒，停 ≥1.2 秒 | 字卡上不放长句（≤ 16 个字）；副标题只补一句怎么用 |
| **窗口俯仰** | `frame: "window"` + `tilt: [俯仰, 偏转]`：原型装进窗口浮在浅底上，标题栏写入口路径；升起、退场、全景用 | 俯仰 10–14°、偏转 ≤15°；移动 0.8–1.3 秒 | 只给建立「在哪儿」的镜头；要读字就 `tilt: [0, 0]` |
| **抽离** | `isolate`：组件的祖先背景、兄弟节点按时间淡掉，组件照常运行，垫一张卡片浮在背景上，自带正视推近 | 淡入淡出各 0.6 秒，`fill` 0.6–0.9 | 抽离的东西关闭前先结束抽离（弹窗关了卡片会空着）；一个场景一两次，多了就是幻灯片 |
| **聚光** | `isolate` + `keep: 0.2`：其余部分留 20%，背景不动 | 同上 | 只给一行、一个标签这种小目标 |
| **定格** | `{ at, hold: 2 }`：原型的时间停住（提示不消失、动画不走），镜头与标注照常动 | 1.5–2.5 秒 | 不改产品行为，只把那一刻拉长；不要拿它掩盖等网络 |
| **逐字输入** | `type`：光标点进输入框、按真键盘一字一字打；`append: true` 接着原内容 | 每秒 10–14 个字 | 文字要有出处（合成数据）；打完停 ≥1 秒再点提交 |
